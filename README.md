## 📋 Overview

Multi-step automation with AI-triggered alerts — monitors data sources and fires smart notifications. Part of a 5-month Cybersecurity + AI + Automation roadmap targeting $2K MRR.

## ✨ Features

- Multi-source data monitoring (APIs, RSS, files)
- AI anomaly detection
- Slack + Email + Telegram alerts
- Cron-based scheduling
- Alert history dashboard

## 🛠️ Tech Stack

- Python
- APScheduler
- OpenAI / Claude API
- Slack API
- FastAPI

## 🚀 Getting Started

```bash
git clone https://github.com/malikatemz/ai-alert-monitoring-system.git
cd ai-alert-monitoring-system
pip install -r requirements.txt
python main.py
```
